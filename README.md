# 🎯 Python Number Guessing Game

A polished, interactive command-line interface (CLI) application that challenges users to guess a randomly generated number. This project demonstrates foundational programming concepts including control flow, error handling, and user experience design.

## ✨ Key Features
* **Intelligent Feedback:** Real-time hints ("Too high" or "Too low") to guide the user toward the correct answer.
* **Robust Input Validation:** Uses `try-except` blocks to handle non-numeric inputs without crashing the program.
* **Score Tracking:** Automatically calculates and displays the total number of attempts upon a successful guess.
* **Modular Architecture:** Written with clean, reusable functions and an entry-point guard.

## 🛠️ Technical Implementation
* **Randomization:** Utilizes the `random` module for unpredictable gameplay.
* **Loop Logic:** Implements a `while` loop for continuous gameplay until the win condition is met.
* **Documentation:** Fully documented in clear, professional English (C2 Level).
